## 📌 Overview

The **Movie Recommendation System** is a **content-based** engine that suggests similar movies based on user input. It fetches real-time data from **TMDb API** and displays it in an elegant **Streamlit UI**.

  <img src="https://media.giphy.com/media/eJ4j2VnYOZU8qJU3Py/giphy.gif" width="600"/>
</p>

---

## 🚀 Features

- 🔍 **Search for a Movie**: Enter a title to get personalized recommendations.
- 🎥 **Top 5 Similar Picks**: Display of top 5 movies based on content similarity.
- 🖼️ **Posters, Ratings, and Overviews**: Visual and text info for easy viewing.
- 🔄 **Robust Error Handling**: Includes retries for API failure cases.
- 🔐 **Secure API Key Handling**: `.env` support to hide credentials.
